# Cycle 4 trust outcome

final held-out generation was prohibited because calibration selected no rule.

## Question, evidence and method

Can the frozen divergence/horizon selectors identify reliable alternatives with
useful coverage in every declared J1 condition? The protocol is
`research/archive/cycle4/protocol_support/trust_signal_experiment_protocol.md`, with pre-outcome executable
specification and timing correction in `cycle4_trust_preoutcome_specification.md`.
Same-window realised epsilon and supplied future inputs make this a post-window
common-input evidence study. It cannot validate current-decision online trust.

The isolated reference imports only `copy` and `random`. Bidirectional transition
and metric mutations, serialization, import and selector feature tests passed
before collection; see `cycle4_trust_source_isolation_audit.md`. Independence of
source does not establish independence of the shared authored traffic specification.

The immutable `results/cycle4-trust/development-20261005-v1` and
`results/cycle4-trust/calibration-20261005-v1` each contain 1,200 runs, 60 full
cells, 20 seed/run units per cell, eight anchors/run and 28,800 all-action pairs.
Development seeds 801–820 validated features only; calibration used 821–840.
Both were executed using source bundle
`results/cycle4-trust/source-freeze-20261005-v1`. Seeds 841–860 were never
generated by this workflow. The final no-access gate is covered by tests;
arbitrary external filesystem activity cannot be proven absent.

`experiments/analyze_cycle4_trust.py` reduces anchors within runs and bootstraps
seeds within cells; global uncertainty resamples seeds shared across cells.
Undefined precision is reported and fails a cell under the disclosed conservative
pre-outcome interpretation. Global ratios below are descriptive pooled counts,
not substitutes for the all-cell rule. Full candidates, cells, runs and intervals:
`tables/cycle4-trust-calibration-v1/`.

No candidate passed all cells. The q=1 divergence rule was baseline-equivalent
on calibration, and all h=20 variants were equivalent to their divergence-only
parent. A binding cutoff h=2/6 necessarily loses entire longer-horizon cells;
this was identified before collection and preserved. Known unsupported incident
semantics force abstention in 1,920/9,600 calibration anchors (12 full cells), so
the all-cell exposure rule could not be met in those cells by any family.

Higher pooled precision came with fewer recommendations and more missed genuine
opportunities. q=.50 coverage at H=20 was only 0.0291, versus baseline 0.4944.
Accepted actions also concentrated on NS_GREEN: 1,149/1,689 q=.50 recommendations,
versus 2,752/4,103 baseline. Per-seed and regime distributions are retained in
the machine selection file and `figures/cycle4-trust-v1/robustness.json`.
Epsilon has no nominal probability guarantee: report empirical error coverage,
never describe it as a calibrated confidence interval.

## Negative controls and oracle

The controls were declared before collection and used calibration only. Shuffled
divergence within compatible H/demand/incident strata had coverage 0.1861 and
precision 0.9916, compared with original q=.50 0.1759 and 0.9840. Predictive
usefulness therefore did not degrade as hoped. This does not establish a specific
incremental divergence signal beyond epsilon and condition-dependent selection.
Constant zero divergence reproduced baseline coverage/precision, as expected.
Constrained label permutations reduced mean run precision (undefined runs counted
as zero) from 0.4191 to a null mean 0.2299; this detects association in the combined
selection machinery, not divergence-specific value or a confirmatory p-value.

The analysis-only oracle found a truly better alternative at 0.5796 of anchors.
Coverage lost by abstention was 0.1682 for baseline and 0.4065 for q=.50. The
oracle never entered selector inputs, reference dynamics or actuation. Choice
value loss in the diagnostic file describes the selected alternative before
abstention; it is not a measured policy-performance loss from deploying a gate.

## Decision and limits

**D: counterfactual validity remains unestablished.** Final held-out result:
**NOT RUN**, rather than a replication failure. Divergence does not have supported
prospective held-out incremental value. Adding horizon has no supported incremental
value: h=20 is nonbinding, and shorter cutoffs violate declared exposure.

The result rejects eligibility of these frozen global selectors under this
all-cell protocol. It does not prove that divergence contains no predictive
information or that all possible uncertainty mechanisms fail: structural
abstention/exposure conflicts contribute to D. Rate-only and combined mismatch
also show empirical errors. No cells are removed or promoted post hoc.
