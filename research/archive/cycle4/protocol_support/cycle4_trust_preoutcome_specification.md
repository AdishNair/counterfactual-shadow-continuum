## Pre-outcome scientific timing defect

The existing baseline epsilon is the absolute difference between same-window mirror utility and realized production utility. Realized production utility exists only after that H-tick production window. Selected-alternative divergence likewise requires the completed supplied-window SEM rollouts. This study provides the future exogenous window to all actions as an offline common-window replay. Accordingly its prospective split concerns new software outcomes, not a signal demonstrated available before the action being evaluated. The phrase decision-time observable is an idealized evidence interface here. **No real production decision-time online reliability claim may follow from this study.** This pre-existing timing defect is documented before outcomes; the original selector formula is preserved. A future truly online study requires a separately frozen causal time ordering and new seeds. Collection is blocked pending director review of this amendment.

## Exact executable choices

- Authored production rate 2 throughout. Aligned control has no heterogeneity, SEM rate 2 and modeled incidents. Heterogeneity-only enables authoritative keyed discharge heterogeneity. Rate-only sets SEM rate 4 with no authoritative heterogeneity. Incident-knowledge-only disables SEM incident modeling with rate 2. Combined applies SEM rate 4 and disabled incident modeling, without heterogeneity. This isolates five declared regimes; names cannot reach the selector.
- Every seed x full-cell run starts from default `State(rng_seed=seed)`. Before each of eight anchors, advance eight ticks with the queue-based authoritative action chosen at history entry, using that cell's authoritative heterogeneity and incident regime. Capture the state; use queue policy to choose production action; execute H future ticks under that action. The future final state starts the next history. This is closed-loop matching-regime anchor generation. Window arrivals use independent deterministic keyed PRNG streams, shared among all three action branches within the anchor. No prior historical anchor series is reused.
- BALANCED serves NS for ceil(H/2) ticks, EW thereafter. Integrated divergence is the **sum**, without normalization, of tickwise Euclidean distance between selected-alternative and mirror `(queue_ns, queue_ew)` traces; units queue-vehicle ticks. Utilities use negative mean total queue. Selection ties within 1e-9 follow action order NS_GREEN, EW_GREEN, BALANCED. Baseline gain uses strict `> epsilon`; divergence uses inclusive `<= d`.
- All comparable anchors, including abstentions and unavailable selector semantics, contribute one divergence to the global calibration quantile population. Quantile index is ceil(q*N)-1. Duplicate rules have identical acceptance vectors across calibration anchors and are retained once, favoring baseline, simpler family, smaller d, shorter h. Baseline-equivalent is recorded separately.
- Eligible decisions mean complete comparable action/mirror/production records, eight per run unless an explicitly recorded failure occurs. Coverage is recommended/eligible; abstention is one minus coverage; precision is true selected-positive/recommended; FPR is false selected-positive recommendation/all selected-reference-nonpositive eligible anchors; FNR is abstained anchors with any truly better alternative/all eligible anchors with any truly better alternative. A bad chosen recommendation is FP, even if some other action is truly better. Incomplete observations are excluded from these denominators but reported against all planned anchors. Unknown/unsupported semantics remain eligible abstentions.
- Undefined precision is counted per run, retained in all cell/global denominators and treated as precision zero for conservative median aggregation. Undefined FPR/FNR are reported and treated as zero for descriptive medians only when no relevant negatives/positives exist. Any undefined precision in a cell fails qualification: this is a **prospective conservative interpretation** of ambiguous cell-level wording, agreed before outcomes, not an unambiguous implication of the original prose. Every cell must also have median recommendation count >=2, >=12 recommending runs, median coverage >=.25, precision >=.95, FPR <=.05, abstention <.75. Bootstrap intervals resample the 20 seeds within cell; global intervals resample the same seed across all 60 cells.
- Selector receives only six exact keys: H, epsilon, estimated gain, divergence, static incident capability and supplied-window incident metadata. It receives no reference outcomes, mismatch labels or oracle statistics. Capability unsupported plus a supplied blocked incident forces abstention. Metadata missing/unknown/late forces abstention. A falsely declared capability cannot be detected without an oracle; adversarial tests record that limitation. Every input is logged.
- Development validates feature calculation, serialization, independent-reference agreement, and semantic status only. No divergence thresholds exist until calibration; no development performance-based selection. The analyzer predefines a diagnostic family display: baseline, q=.50 divergence, and q=.50/H<=20 divergence+horizon. It also displays the whole frozen calibration grid. These diagnostics cannot qualify a failed candidate or produce a new rule.
- h=2/6 necessarily fails H=20 exposure; unsupported incident cells may force zero coverage. These are frozen falsifiable limitations, not grounds to relax the gate.
